# 8. Технологии

## Приложение

| Технология      | Область применения                 | Мотивационная часть                                                                                    |
| --------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Golang          | Бекенд бизнес-логика, микросервисы | Быстрый и популярный язык, механизм горутин, большая экосистема. Хорошо подходит для сетевых сервисов. |
| Docker          | Контейнеризация                    | Стандарт для упаковки сервисов и зависимостей. Упрощает локальную разработку, CI/CD и деплой.          |
| React+TS        | Браузерный клиент                  | Популярный стек для web-клиента. TypeScript помогает ловить ошибки до runtime.                         |
| React Native+TS | Мобильный клиент                   | Позволяет делать iOS и Android на одном стеке. Можно переиспользовать часть подходов и кода из web.    |

## Хранилища

| Технология            | Область применения                                                             | Мотивационная часть                                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenSearch            | Поиск по пользователям, сообществам и контенту                                 | Полнотекстовый поиск, фильтрация, индексы. Не хотим зависеть от Elastic.                                                                             |
| Redis                 | Локальный кеш в каждом ДЦ: лента, счетчики, session lookup, rate limit         | Быстрый in-memory кеш. Снижает нагрузку на БД. Не является source of truth; canonical refresh-сессии хранятся в PostgreSQL.                          |
| SeaweedFS             | Origin-хранение файлов: фото, видео, аватары                                   | Простое и распределенное open source s3 хранилище                                                                                                    |
| Postgres HA (Patroni) | БД для пользователей, профилей, сообществ, подписок, прав доступа и метаданных | Реляционная БД для данных, где нужны транзакции, связи, уникальные ограничения и проверки прав.                                                      |
| ScyllaDB              | БД для активных данных: лента, лайки, комментарии, сообщения                   | Колоночная БД, быстрая запись, встроенная репликация и шардирование. Используем единый multi-DC кластер: RF=1 на каждый ДЦ, суммарно RF=3, `QUORUM`. |
| Kafka                 | Очередь сообщений, события между сервисами и датацентрами                      | Стандартный брокер сообщений с гарантированной доставкой. Нужен для асинхронной обработки: ленты, поиска, счетчиков и внутренних задач.              |
| Etcd                  | Конфиг и сервис-дискавери                                                      | Классика для Kubernetes, дружит с Patroni. Подходит для конфигурации и координации компонентов кластера.                                             |

## Мониторинг

| Технология   | Область применения | Мотивационная часть                                                                |
| ------------ | ------------------ | ---------------------------------------------------------------------------------- |
| Prometheus   | Метрики            | Стандарт для сбора метрик и алертинга. Подходит для сервисов, БД и инфраструктуры. |
| Grafana      | Дашборды и алерты  | Удобные дашборды по метрикам: сервисы, БД, Kafka lag, кеши, датацентры.            |
| Loki+Alloy   | Логи               | Централизованный сбор и хранение логов. Alloy собирает, Loki хранит.               |
| Jaeger+Tempo | Трейсинг           | Трейсинг запросов между микросервисами, БД, кешами и очередями.                    |

## Инфраструктура

| Технология | Область применения                               | Мотивационная часть                                                                                             |
| ---------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Nginx      | L7-балансировка, SSL-терминация, раздача статики | Простой L7 балансировщик, который умеет в SSL, маршрутизацию, rate limiting, проксирование API и статики.       |
| Kubernetes | Оркестрация контейнеров бэкенда                  | Стандарт для запуска микросервисов. Деплой, service discovery, health checks, rolling updates, масштабирование. |
